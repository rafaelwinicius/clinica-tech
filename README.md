# Clínica-Tech

Projeto acadêmico desenvolvido para propor uma solução tecnológica voltada ao gerenciamento de agendamentos e atendimentos em uma rede de clínicas populares.

## Proposta

A Clínica-Tech atua com soluções de Tecnologia da Informação para a área da saúde.

A solução proposta consiste em uma plataforma web integrada ao WhatsApp, destinada ao gerenciamento centralizado de unidades, profissionais, agendas e atendimentos, permitindo:

- agendamento pelo paciente via WhatsApp;
- agendamento presencial pela secretaria;
- consulta de disponibilidade de profissionais;
- cancelamento e remarcação;
- envio de lembretes e confirmações;
- acompanhamento dos atendimentos realizados;
- gerenciamento das unidades e agendas da rede.

## Estrutura da equipe

O projeto foi dividido entre cinco áreas:

1. Product Owner + Análise de Requisitos
2. UX/UI + Acessibilidade
3. Front-end
4. Back-end + Segurança da Informação
5. Banco de Dados + QA/Testes

## Organização do repositório

### 02-ux-ui
Documentação referente à experiência do usuário, interface e acessibilidade.

### 03-frontend
Documentação referente às interfaces e estrutura do front-end.

### 04-backend-seguranca

### 05-banco-qa

### 06-organizacao

### 07-apresentacao-final
Apresentação consolidada do projeto.

## Fonte oficial das decisões do produto

As definições oficiais de escopo, requisitos, regras de negócio e MVP estão documentadas em:

`01-produto-requisitos/produto-e-requisitos.md`

As demais áreas devem utilizar esse documento como referência para o desenvolvimento de suas respectivas entregas.

## Fluxo de trabalho

Cada integrante trabalhará em uma branch específica da sua área, realizará seus commits e abrirá uma Pull Request para revisão antes do merge na branch `main`.

Exemplos:

- `feature/ux-ui`
- `feature/frontend`
- `feature/backend-seguranca`
- `feature/banco-qa`

## Entregas por integrante

Cada área deverá produzir:

- documentação em Markdown;
- proposta individual de postagem para o LinkedIn;
- apresentação em PowerPoint referente à sua contribuição.

Após a aprovação das Pull Requests, as apresentações serão consolidadas na versão final do projeto.
